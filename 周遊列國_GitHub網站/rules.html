規則

3 隊、20 國、限時 25 分鐘。找到國旗、全隊合影，就能佔領該國。

01概要

3
隊伍：藍隊、黃隊、綠隊
20
國旗：散布在場地各處，順序不依棋盤格號
25
分鐘：時間到即結束，以佔領格數計分

02進行方式

  1. 回本部擲骰。骰子由主持人掌握，各隊必須回到本部，由主持人擲骰決定前進格數。
  2. 前進並確認國家。棋盤順時針，藍隊從 Taiwan、黃隊從 Turkey、綠隊從 Spain 出發；網站會顯示該隊現在所在的國家。
  3. 尋找國旗。在場地中找到該國國旗，國旗位置依區域給予線索。
  4. 全隊合影。全隊與國旗入鏡，拍一張照片，在自己隊伍的欄位上傳。
  5. 佔領。上傳成功即佔領該格，棋盤上該格改為合影，外框換成隊伍顏色，並計 1 分。
  6. 回本部繼續。每次只能有一個進行中的目標，拍完才能再回本部擲骰。

03佔領與計分

  1. 每佔領一格得 1 分。最終分數 = 佔領格數 + 主持人加減分。
  2. 強勢佔領。走到已被他隊佔領的格子，完成合影即可搶下，原佔領隊伍失去 1 分。
  3. 自己的格子。走到自己已佔領的格子，不必拍照，直接回本部再擲一次。
  4. 挑戰中的格子要重擲。某隊正在某一格挑戰（尚未完成合影）時，其他隊擲到同一格，須重新擲骰；該隊完成或放棄後，這一格才開放。
  5. 放棄。放棄這一格不得分，由主持人操作；放棄後即可回本部繼續。

04結算

  1. 時間到，棋盤顯示最終排名；最高分的隊伍獲得額外食物。
  2. 同分時，並列名次。
