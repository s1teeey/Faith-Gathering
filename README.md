# Faith 區｜分區聚會

2026 年 7 月至 11 月分區聚會的活動紀錄，以及 11 月「周遊列國」的遊戲網站（GitHub Pages 靜態頁面；遊戲狀態、照片與計時由 Google Apps Script 後端提供）。

- 首頁：`index.html`（7、8、9、11 月活動紀錄）
- 遊戲：`game.html`
- 大螢幕：`game.html?view=screen`
- 關主：`game.html?admin=密碼`
- 11 月規則：`nov.html`

設定：把 Apps Script 部署後的 `/exec` 網址貼到 `config.js` 的 `API_URL`。
